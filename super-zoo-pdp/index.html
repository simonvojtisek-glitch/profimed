🐕 Antiparazitika pro psy Product Category Framework

! Výzva: Perplexity Paradox

LLM shopping agenti (ChatGPT Shopping, Google Gemini, Perplexity) potřebují strukturovaná data pro filtrování a sémantický kontext pro doporučování.

❌ Problém

  • • Super zoo má základní atributy (paraziti, doba účinnosti)
  • • Ale chybí sémantická vrstva (pro koho, proč)
  • • Chybí L6 constraints (anti-hallucination)
  • • Popisy produktů jsou prázdné nebo minimální
  • • LLM agenti nemohou produkty správně doporučit

✓ Řešení

  • • Blueprint: 6-vrstvá strukturovaná data
  • • Description: 7 sémantických bloků
  • • MCL: Merchant trust layer
  • • LLM agenti mohou najít, porovnat, doporučit
  • • Zákazníci získají jasné odpovědi na své otázky

⚡ Architektura: Blueprint + Description + MCL

🗂 Blueprint Layers (L1-L6)

L1

Core Identity

Unikátní identifikace produktu

Parametry

brand: "Foresto"
product_line: "Antiparazitní obojky"
sku: "FRS-70-DOG"
gtin: "4007221038184"
category_path: "Psi > Zdraví > Antiparazitika"

Účel pro LLM

Entity resolution — umožňuje přesné rozpoznání produktu a porovnání napříč prodejci. Předchází záměně podobných modelů.

L2

Customer Goals ⭐ OUTFINDO UNIQUE

Mapování produktu na zákaznický záměr

🎯 Toto je klíčový diferenciátor. Konkurence má specifikace; my máme intent mapping. LLM může spárovat dotazy jako "obojek pro velkého psa co chodí do lesa" přímo se strukturovanými poli.

Parametry

target_user_types: ["hassle-free-protector", "safety-first-family"]
dog_profile_fit: ["adult", "senior", "large-breed"]
household_fit: ["with-children", "multi-pet"]
problems_solved: ["tick-prevention", "flea-control", "long-term-protection"]
lifestyle_fit: ["outdoor-active", "frequent-swimmer"]
primary_goal: "continuous-worry-free-protection"

Research Grounding

Odvozeno z Customer Profiles a Goals reportů:

  • • Hassle-Free Protector (30-40%) → priority_goal: continuous protection
  • • Safety-First Family (20-25%) → household_fit: with-children
  • • Goal Priority 9: "Maintain worry-free protection"
L3

Core Specifications

"Stačí mi to?" — klíčové metriky výkonu

Parametry

duration_effectiveness_months: 8
target_parasites: ["fleas", "ticks", "lice"]
onset_of_action_hours: 24
suitable_dog_weight_kg: {"min": 8, "max": null}
active_ingredient: "imidacloprid + flumethrin"
mode_of_action: ["repellent", "insecticide"]

Účel pro LLM

Umožňuje constraint-based filtering: "obojek s účinností alespoň 6 měsíců", "proti klíšťatům i blechám", "pro psa nad 25 kg".

Pain Point Addressed

• Gaps between treatments (0.82) → duration_effectiveness

• Incomplete parasite coverage (0.68) → target_parasites[]

L6

Constraints & Boundaries ⚠️ CRITICAL FOR AI

"Co by mě mohlo překvapit?" — anti-hallucination layer

🚨 Bez explicitních constraints může LLM doporučit produkt pro nevhodné případy. Tato vrstva umožňuje odpovědná doporučení a snižuje vratky.

Parametry

suitable_for: ["dogs-over-8kg", "puppies-from-7-weeks", "outdoor-dogs", "swimming-dogs"]
not_suitable_for: ["cats", "dogs-under-8kg", "puppies-under-7-weeks", "sick-dogs-without-vet-consult"]
this_is_not: ["dewormer", "spray", "drops", "treatment-for-existing-worms"]
requires: ["vet-consult-if-pregnant", "vet-consult-if-sick"]
limitations: ["efficacy-may-reduce-after-frequent-bathing", "not-100%-tick-repellent"]
incompatible_with: ["permethrin-products-near-cats"]

Pain Points Prevented

  • • Unsafe for puppies/small breeds (0.48)
  • • Toxicity to other pets (0.40)
  • • Misidentified parasite treatment (0.65)
  • • Reduced efficacy after bathing (0.89)

Example LLM Query Handled

"Mám malého čivavu 4 kg a kočku. Je Foresto vhodný?"

→ L6 data: not_suitable_for contains "dogs-under-8kg" + "cats" → LLM correctly declines

🏪 MCL — Merchant Consideration Layer

Per-offer, per-merchant data pro nákupní rozhodnutí. Na rozdíl od Blueprint (produktová data) je MCL o nákupní zkušenosti u konkrétního prodejce.

Tier 1: Identity

  • • Merchant name
  • • Legal entity (IČO)
  • • Trust badges
  • • Heureka ověřeno

Tier 2: Logistics

  • • Shipping options
  • • Delivery times
  • • Stock availability
  • • Click & collect

Tier 3: Transactional

  • • Return policy (14/30 days)
  • • Warranty
  • • Payment methods
  • • Policy URLs

Tier 4: Consensus

  • • Trust scores
  • • Review aggregation
  • • Authorized dealer
  • • MCS scoring

📋 Schema.org compliance: MerchantReturnPolicy, OfferShippingDetails, Offer properties

🐕 Specifika pro antiparazitika

L6: Critical Safety Layer

Pro antiparazitika je L6 obzvláště kritická kvůli:

  • • 🐱 Toxicita pro kočky (permethrin)
  • • 🐶 Věkové a váhové limity
  • • 🤰 Březí a kojící feny
  • • 💊 Interakce s léky
  • • ⚠️ "Tohle NENÍ" — odčervovací přípravek

Key Market Divisions

Hlavní osy segmentace produktů:

  • • 💧 Application method (collar vs drops vs spray)
  • • ⏱️ Duration (1 month vs 8 months)
  • • 🎯 Target parasites (fleas only vs broad-spectrum)
  • • 🌿 Ingredient type (synthetic vs natural)
  • • 📏 Dog size/age (puppy, small, large)
