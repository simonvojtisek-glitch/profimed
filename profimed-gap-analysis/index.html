🎯 Prioritní doporučení

1
L2: Customer Goals — Přidat sémantické mapování
Kritický gap pro LLM discovery
Přidat fieldy:
  • • target_user_types[] — "citlivé dásně", "rodiče malých dětí", "cestovatelé"
  • • problems_solved[] — "plak u rovnátek", "motivace dětí k čištění"
  • • suitable_contexts[] — "cestování", "sdílená domácnost"
Dopad:
LLM agenti budou moci matchovat dotazy jako "kartáček pro citlivé dásně pro manželku" přímo na strukturovaná data místo inference z popisu.
2
L6: Constraints — Anti-halucinační vrstva
Prevence špatných doporučení
Přidat fieldy:
  • • not_suitable_for[] — "batolata pod 3 roky", "bez dohledu rodiče"
  • • this_is_not[] — "náhrada za zubní nit", "ústní sprcha"
  • • incompatible_with[] — "hlavice jiných značek"
Dopad:
Zabrání LLM agentům doporučit dětský kartáček pro kojence nebo tvrdit, že kartáček nahrazuje dentální hygienu.
3
D1-D7: Description Blocks
Sémantický obsah pro konverzi
Vytvořit 7 description bloků pro každý produkt, grounded v customer research. Prioritizovat D2 (Hodí se to na mě?) a D7 (Co mě překvapí?) — tyto přímo adresují top pain points z výzkumu.
4
L4: Physical Parameters
Doplnit chybějící rozměry
Přidat weight_g, length_mm, head_size_mm pro filtrování dle fyzických parametrů (např. "malý kartáček do kufru").
